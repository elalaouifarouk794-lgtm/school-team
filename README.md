Madrasati Football - version corrigée.

Important : ne téléversez pas le ZIP comme si c'était le site. Décompressez-le, puis mettez à jour le fichier index.html du dépôt GitHub : ouvrez index.html > Edit (crayon) > remplacez tout le code par le contenu de ce nouveau index.html > Commit changes. Attendez la publication, puis faites Ctrl+F5 sur le site.

La suppression est individuelle et demande confirmation. La simulation est fictive et ne modifie pas les scores officiels. Les données restent locales au navigateur.
